\begin{abstract}
本ノートは、Cobham の明示的仮定を除いた Full General ARC 証明について行った公開後監査の改訂版である。監査対象は、(A1) base-2 finite-kernel automaticity から奇数部分列の base-3 automaticity への transfer、(A2) 奇数部分列 change set の dyadic nowhere-thickness、(A3) odd-base automatic support に対する topological pumping と finite-support 結論、(A4) 主定理が前件空偽として真になっていないか、また $0$ を結論から除外することが本当に sharp か、の4点である。

今回、A1--A4 の全てについて第二の紙上再構成経路を作り、それぞれを別個の Lean 4 audit file として形式化した。独立性の範囲は項目ごとに明示する。A1 は旧 packaged transfer result を使用しない。A2 は lower local-density theorem を再利用する一方、A2 固有の affine pullback を独立に再構成する。A3 は lower infrastructure を再利用するが、監査対象である packaged Stage 6--10 conclusion を直接使用しない。全 audit file は Lean kernel による型検査（standalone の \code{lake env lean}）を通過し、対応する targeted \code{lake build} も成功した。主要 endpoint の \code{\#print axioms} は \code{propext}, \code{Classical.choice}, \code{Quot.sound} の標準的依存のみを報告し、\code{sorryAx} は報告されなかった。公開済み Full General ARC 定理に対する反例や確定した欠陥は、本監査では得られていない。

改訂版で最も重要な変更は、旧版が source-level trace または継続監査として残していた A1--A3 を、独立の数学的再構成と Lean 再検証まで進めた点である。A1 は $2$ の modulo $3^j$ における primitive-root 性を用いて base-3 residual を base-2 kernel に埋め込み、A2 は lower local-density theorem から $x=2n+1$ の affine pullback を再構成し、A3 は odd-base pumping から dyadic residue permutation、child filling、nowhere-thickness との矛盾へ至る chain を再構成した。A4 では任意の base $B\ge2$ に対して $a(0)=x$, $a(n)=y$ ($n>0$) という明示的 witness を直接形式化した。

ここで ``Independent'' とは、監査対象となる packaged endpoint をそのまま使用せず、より下位の部品から別経路で再構成したという意味である。第三者による外部 peer review や、再利用した全ての lower lemma を含む import graph の完全分離を意味するものではない。
\end{abstract}

\section{位置づけと目的}

親論文が扱う shortcut Collatz map は
\[
T(n)=
\begin{cases}
 n/2, & n\equiv0\pmod 2,\\[2mm]
 (3n+1)/2, & n\equiv1\pmod 2
\end{cases}
\]
である。Full General ARC の主張は、任意の base $B\ge2$ に対し、$a:\Nzero\to\alpha$ が finite base-$B$ kernel を持ち、
\[
a(T(n))=a(n)\qquad(n\in\Nzero)
\]
を満たすならば、$a$ は正の整数上で定数になる、という剛性定理である。$n=0$ の値については自由度が残る。

旧版の監査ノートでは4つの攻撃点を切り分けた。今回の改訂では、その全てについて紙上の独立再構成と別個の Lean 検証まで完了した。本ノートで \textbf{CLOSED} と記すのは、その特定の監査上の疑義に対して独立再構成と Lean check が成立した、という意味であり、将来の数学的検討や文献監査が不要になるという意味ではない。

\section{Audit A1：base-3 kernel transfer の独立再構成}

$a:\Nzero\to\alpha$ が
\[
a(2n)=a(n),\qquad a(2n+1)=a(3n+2)
\]
を満たすとし、
\[
b(n)=a(2n+1)
\]
とおく。監査対象は
\[
\K_2(a)\text{ finite}\quad\Longrightarrow\quad\K_3(b)\text{ finite}
\]
である。改訂監査では、以前の ARC2 transfer theorem を直接呼ばずに、この含意を kernel の定義から再構成した。

\subsection{紙上の独立再構成}

$b$ の任意の base-3 kernel residual を
\[
v(n)=b(3^e n+r),\qquad 0\le r<3^e
\]
とする。odd branch を1回使うと
\[
\begin{aligned}
v(n)
 &=a\bigl(2(3^e n+r)+1\bigr)\\
 &=a\bigl(3^{e+1}n+(3r+2)\bigr)
\end{aligned}
\]
である。$j=e+1$, $c=3r+2$ とおけば
\[
0<c<3^j,\qquad 3\nmid c.
\]
$2$ は modulo $3^j$ の primitive root なので、ある $s\ge0$ が存在して
\[
2^s c\equiv-1\pmod{3^j}
\]
となる。したがって
\[
2^s c+1=q3^j
\]
となる $q\ge1$ が存在する。even identity を繰り返し、odd identity を逆向きに用いると
\[
a(3^j n+c)=a\bigl(2^{s+j}n+R\bigr),
\qquad R=2^j q-1
\]
を得る。さらに
\[
0\le R<2^{s+j}
\]
なので、右辺は $a$ の genuine base-2 kernel residual である。従って
\[
\K_3(b)\subseteq\K_2(a),
\]
よって $\K_2(a)$ が有限なら $\K_3(b)$ も有限である。Cobham theorem、Collatz 収束、finite alphabet は不要である。

\subsection{独立 Lean audit}

\begin{center}\code{ARCA1IndependentAudit_v2.lean}\end{center}
は上の再構成を形式化し、\code{arc_three_kernel_odd_finite}, \code{arc_three_kernel_odd_subset}, \code{arc_lemma3_1} を直接使用しない。standalone の \code{lake env lean ARC/ARCA1IndependentAudit_v2.lean} は成功し、その後の targeted module build も成功した（記録時の project state で 8767 jobs）。主要 endpoint の axiom report は \code{propext}, \code{Classical.choice}, \code{Quot.sound} のみである。

\subsection{A1 の監査結論}

base-3 odd-subsequence automaticity は、元の packaged theorem とは別経路の紙上 proof と Lean proof の両方で再確認された。未知の Collatz 収束性を暗黙に使っているのではないか、という A1 の具体的疑義は本監査の範囲で CLOSED とする。
\section{Audit A2：dyadic thinness の独立再構成}

\[
b(n)=a(2n+1),\qquad
\D_b=\{n\in\Nzero:b(n)\ne b(n+1)\}
\]
とする。監査対象は shortcut-Collatz arithmetic と dyadic residue class の橋渡しである。改訂監査では A2 固有の affine pullback を lower local-density theorem から直接作り直した。

\subsection{独立 affine pullback}

任意の dyadic parent
\[
n\equiv r\pmod{2^m}
\]
に対し
\[
x=2n+1
\]
と置くと
\[
x\equiv2r+1\pmod{2^{m+1}}
\]
である。この odd affine image に対して、既証明の base-independent local-density theorem を gap $H=2$ で適用する。すると、より深い integer dyadic child 上で
\[
a(x)=a(x+2)
\]
が成立する。監査 proof は、その child の preimage として元の $n$-variable にさらに深い child を明示的に構成し、その全体が元の parent 内にあり、かつ affine image 全体が local-density child に入ることを示す。したがって
\[
a(2n+1)=a(2n+3),
\]
すなわち
\[
b(n)=b(n+1)
\]
が child 全体で成立する。integer cylinder を natural residue class に変換すれば、positive representative を持つ empty-change child が得られ、$\D_b$ は dyadically nowhere thick となる。

\subsection{A2 の監査結論}

affine conversion は source trace に留まらず、lower local-density interface から別形式の Lean proof として再構成された。従って A2 の具体的疑義は CLOSED とする。local-density theorem 自体をさらに攻撃するなら、それは別の下位監査項目である。
\section{Audit A3：odd-base topological pumping の独立再構成}

odd base $q\ge3$ とし、$s:\Nzero\to\{0,1\}$ が finite base-$q$ kernel を持つとする。監査対象は、support が dyadically nowhere thick なら有限である、という mixed-base statement である。automaton は $q$ の冪で動き、thinness は $2$ の冪で測られるため、ここが最も構造的に繊細な橋である。

\subsection{紙上の独立再構成}

support が無限と仮定する。finite MSD automaton では、state 数より長い positive canonical support word を取ることができ、非空 loop block が得られる。loop を2重化して pump すると数値 family は
\[
N_k=N_0+dG_k,
\qquad
G_k=1+Q+\cdots+Q^{k-1},
\qquad Q=q^{2L}
\]
となる。$L>0$ であり、positivity から $d>0$。よって
\[
d=2^s(2v+1)
\]
と書ける。$q$ は odd なので
\[
Q=q^{2L}\equiv1\pmod4.
\]
さらに
\[
j-i=2^t(2u+1)
\]
なら doubled-loop geometric-sum arithmetic から
\[
N_j-N_i=2^{s+t}(2z+1)
\]
という exact dyadic displacement を得る。

$0\le i<j<2^M$ なら $j-i<2^M$ なので $t<M$。従って規格化した pump residue は modulo $2^M$ で全て異なる。index も residue class も $2^M$ 個なので、この residue map は permutation である。$2^s$ と offset $N_0$ を戻すと、pumped support family は1つの dyadic parent の全 deeper child を hit する。一方、dyadic nowhere-thickness は全 parent に empty positive child が存在すると要求する。両者は矛盾するため、support は有限でなければならない。

\subsection{独立 Lean audit}

\begin{center}\code{ARCA3IndependentAudit.lean}\end{center}
は residue permutation、child filling、nowhere-thickness collision、finite support までを新しい audit theorem 名で再構成し、監査対象である packaged Stage 6--10 conclusion を直接呼ばない。

一方で、finite-kernel-to-MSD bridge、Stage 5 の exact dyadic pumping handoff、generic long canonical word lemma などの lower ingredient は再利用する。generic long-word lemma を含む import が transitive に later stage も読み込むため、本監査は厳密には「Stage 6--10 packaged conclusion の direct non-use reconstruction」であり、import graph の完全分離ではない。この制限は明示しておく。

standalone Lean check は成功し、\code{lake build ARC.ARCA3IndependentAudit} も記録時 8819 jobs で成功した。\code{arcA3_oddPumpResidueMap_injective}, \code{arcA3_evenLoopPumpedFamily_hits_every_child_of_exact_two_factor}, \code{arcA3_child_filling_not_nowhereThick}, \code{arcA3_kernelAutomatic_nowhereThick_support_finite}, \code{arcA3_target} など主要 endpoint は \code{propext}, \code{Classical.choice}, \code{Quot.sound} のみを報告した。

\subsection{補助的 Cantor 型 sanity check}

旧版で反例候補として検討した
\[
C=\left\{\sum_{i\ge0}\varepsilon_i3^i:\varepsilon_i\in\{0,1\},\text{有限個のみ非零}\right\}
\]
についても finite residue enumeration を行った。有限版 $C_L$ はテスト範囲の modulo $2^m$ で有限 $L$ により全 residue を覆い、この候補から empty dyadic child を作る evidence は得られなかった。この計算は proof ではないが、formal child-filling mechanism と同方向の sanity check である。

\subsection{A3 の監査結論}

odd-base pumping と dyadic topology の橋は、紙上および別 Lean chain の両方で再構成された。「異種基底の compatibility を仮定しているだけではないか」という A3 の具体的疑義は CLOSED とする。
\section{Audit A4：前件空偽と $0$ の sharpness の独立確認}

任意の $x,y\in\alpha$ に対して
\[
a(0)=x,\qquad a(n)=y\quad(n>0)
\]
と定義する。任意の base $B\ge2$ で、この列の kernel residual は元の列または定数列 $n\mapsto y$ のどちらかなので
\[
|\K_B(a)|\le2
\]
である。また $T(0)=0$ かつ $n>0$ なら $T(n)>0$ なので
\[
a(T(n))=a(n)\qquad(n\ge0)
\]
が成立する。$x\ne y$ とすれば $a(0)\ne a(1)$ である一方、正の整数上では定数である。従って theorem の hypothesis class は全 base で明示的に非空であり、$0$ の自由度も genuine である。

\subsection{独立 Lean audit}

\begin{center}\code{ARCA4IndependentAudit_v2.lean}\end{center}
は prior sharpness package や Full General endpoint を用いず、任意の $B\ge2$ について kernel finiteness と shortcut invariance を直接証明する。\code{arcA4_bool_witness} は Boolean による完全に具体的な witness である。

初版には1か所 local proof goal が残ったが、v2 で正の index 上の値を既証明 lemma から直接与える形に修正した。最終 standalone check では \code{sorryAx} が消失し、\code{lake build ARC.ARCA4IndependentAudit_v2} は記録時 8845 jobs で成功した。主要 endpoint は標準依存のみを報告した。

\subsection{A4 の監査結論}

vacuous truth と $0$ の sharpness の両方は、全 base に共通する two-state-kernel witness によって構成的に CLOSED となった。
\section{本物の反例に必要な条件}

Full General ARC を反証するには、「Collatz 軌道ごとに色を付ける」「疎な automatic set を考える」「even branch だけを満たす」といった構想だけでは不十分である。真の反例は、ある $B\ge2$ と $a:\Nzero\to\alpha$ を明示し、次の3条件を同時に満たさなければならない。
\begin{enumerate}[label=(\roman*)]
\item full base-$B$ kernel $\K_B(a)$ が有限である。
\item 全ての $n\ge0$ で $a(T(n))=a(n)$ が成立する。
\item 正の整数 $m,n$ が存在して $a(m)\ne a(n)$ となる。
\end{enumerate}
例えば未知の非自明 loop や発散 component ごとに色を付けられたとしても、それだけでは (i) の finite-kernel 性は全く保証されない。また
\[
a(2^kq)=a(q)
\]
という延長は even relation を保証するだけで、odd relation
\[
a(2n+1)=a(3n+2)
\]
を自動的には保証しない。

\section{現在の監査判定}

旧版で切り分けた4つの監査対象は、今回すべて第二の紙上再構成経路と別 Lean kernel 検証まで完了した。なお A2・A3 は、再利用する lower lemma の範囲を明示した上で CLOSED と判定する。
\begin{enumerate}[label=\arabic*.]
\item \textbf{A1 CLOSED.} base-3 odd-subsequence kernel transfer を kernel 定義から別経路で再導出し、旧 packaged transfer lemma なしで形式化した。
\item \textbf{A2 CLOSED.} affine dyadic pullback を lower local-density theorem から独立再構成し、Lean で検証した。
\item \textbf{A3 CLOSED.} odd-base residue permutation から dyadic child filling、nowhere-thickness との矛盾までを direct non-use audit chain として再構成し、Lean で検証した。
\item \textbf{A4 CLOSED.} 全 base $B\ge2$ に共通する explicit two-state-kernel witness により、前件空偽と $0$ の genuine freedom を確認した。
\end{enumerate}

これら4点について、確定した数学的欠陥、未知の Collatz convergence premise、Cobham handoff、\code{sorryAx} は見つからなかった。ただし通常の数学的慎重さは残る。今回の4点より下位の lemma、formal modeling、文献との重複などは、将来別の監査対象になり得る。
