# ARC5 papers

This directory contains the final ARC5 manuscripts.

Released files:

- [ARC5_English.pdf](ARC5_English.pdf) — English Lean-verified manuscript
- [ARC5_Japanese.pdf](ARC5_Japanese.pdf) — Japanese Lean-verified manuscript

The ARC5 result concerns 5-automatic sequences invariant under the shortcut Collatz map. Its main proof route does not use Cobham's theorem; it proceeds through local synchronization, dyadic thinness, base-5 pumping, finiteness of the change set, eventual constancy, and propagation by doubling invariance.
