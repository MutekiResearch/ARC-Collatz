# ARC-Collatz

A mathematical investigation related to the Collatz map.

## About this project

This repository contains a mathematical paper and its accompanying Lean formalization related to the ARC investigation.

The purpose of this work is to study structural restrictions associated with the Collatz map.

**This work does not claim to prove the Collatz conjecture.**

- Research paper (PDF)
- Lean formalization / verification files
